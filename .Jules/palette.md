## 2024-05-05 - Accessible Skip-to-Content with Sticky Headers
**Learning:** When adding a "skip to main content" link to an application with a sticky global header, the link must be styled with a high z-index and absolute positioning so it renders *over* the sticky header when focused. Additionally, the target container (`<main>`) must be programmatically focusable (`tabIndex={-1}`) but visually hidden (`focus:outline-none`) to prevent an unwanted visual focus ring from appearing around the entire page content upon jump, maintaining visual polish while serving screen readers and keyboard users correctly.
**Action:** When implementing skip links in new Next.js apps, always use a dedicated policy in `constants/policy.ts` for the focus state styles (using `sr-only focus:not-sr-only focus:absolute ...`), ensure it sits above the header, and add `tabIndex={-1}` and `focus:outline-none` on the target `#main-content`.
