## 2024-05-25 - Internal Anchor Link Targets and Focus Management
**Learning:** When creating internal anchor links (like a "skip to main content" link targeting `#main-content`), ensuring the target element can receive programmatic focus is crucial for screen readers and keyboard navigation. However, applying `tabIndex={-1}` makes it programmatically focusable but can introduce an unwanted default browser focus ring when navigated to, disrupting the visual experience if the target is just a layout container (like `<main>`).
**Action:** Always append the Tailwind `focus:outline-none` class alongside `tabIndex={-1}` for non-interactive anchor targets. This guarantees robust accessibility (focus is correctly shifted) while maintaining a clean, invisible UX (no unsightly focus rings on structural containers).
