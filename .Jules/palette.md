## 2025-01-20 - Skip to Content Link and Programmatic Focus
**Learning:** Next.js and complex component layouts often bury the `<main>` tag, making a 'Skip to main content' link difficult to implement elegantly if the target element isn't focusable. Adding an anchor near the body but styling it using `sr-only` coupled with `focus:not-sr-only` is standard, but the target `<main>` *must* have `tabIndex={-1}` and `focus:outline-none` so it can programmatically receive the focus to handle screen-readers properly without adding an ugly ring outline on the container.
**Action:** When implementing 'skip to content' or programmatic anchoring to structural layout containers, always remember to add `tabIndex={-1}` and `focus:outline-none` to the structural container. Keep these styles in the central policy configurations for consistency.
